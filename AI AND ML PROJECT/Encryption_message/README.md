
# 🔐 Caesar Cipher - Python Implementation

A simple Python script to perform Caesar Cipher encryption on any text input. This tool lets users enter their own message and shift value to generate encrypted cipher text.

---

## 📌 Features

- Encrypts any text using Caesar Cipher.
- Accepts **user input** for text and shift value.
- Preserves spaces, punctuation, and case.
- Easy to run, no extra libraries required.

---

## 🧠 What is Caesar Cipher?

Caesar Cipher is a basic encryption technique where each letter in the plaintext is **shifted** a certain number of places down the alphabet.

Example with shift = 3:

```

Plain:  A T T A C K   A T   D A W N
Cipher: D W W D F N   D W   G D Z Q

````

---

## 🚀 How to Run

1. Save the script as `caesar_cipher.py`.
2. Run the script using:

   ```bash
   python caesar_cipher.py
````

3. Enter your message and shift value when prompted.

---

## 🧪 Example

```
Enter text to encrypt: Hello World!
Enter shift value (e.g., 3): 5

🔐 Cipher Text: Mjqqt Btwqi!
```
